E-commerce listing monitoring

Rule 6(10), inserted by the 2017 amendment, requires an online listing to carry the same mandatory declarations the pack does. Sellers often upload that block as a JPEG instead of page text, which defeats an ordinary scraper — so image assets are pushed through the same OCR pipeline as a physical label before the rule engine sees them.
